## 验证中发现并修复的失真

迁移初版存在 7 类「肉眼难发现、逐字比对才暴露」的失真，均已按 TDD 修复（先写失败测试，再改实现）：

1. **发布日期差一天**：旧站 `<time datetime>` 带 `+08:00` 偏移，显示却是 UTC 日。迁移改为取 datetime 原值，交给站点 `timezone: 'UTC'` 换算。
2. **日期二次叠加时区**：front-matter 里带引号的 ISO 字符串会被 Hexo 当本地时间再加 8 小时。迁移改为输出无引号 YAML 时间戳（Date 对象）。
3. **加粗字面泄漏 `**`**：`**CPU：**计算机` 这类「闭合符前是中文标点」的写法 CommonMark 不认，会原样显示星号。迁移改为输出 `<strong>` 原生标签。
4. **`1.` 被当成空列表项**：段落内单独成行的编号被渲染器吃掉。迁移时转义为 `1\.`。
5. **直引号被智能标点转换**：渲染器默认 `smartypants: true`，把正文里的 `'` 转成 `’`。旧站正文的弯引号是历史渲染结果、已固化在迁移后的 Markdown 里，因此关闭该选项（`_config.yml` 的 `marked.smartypants: false`），避免二次转换；3 篇手写稿按旧站实际字符存原文。
6. **正文表格被整体压平**：turndown 默认没有 table 规则，26 张正文表格（分布在 6 篇文章）的单元格被拆成连续段落，行列关系全丢。迁移改为 `keep(['table'])` 保留 HTML 表格。
7. **列表项里的代码块被截断**：围栏回填到列表项时只有首行带列表标记，代码行顶格，CommonMark 会把它们踢出列表——正文漏出代码文本、代码块数量凭空多一块（爬虫005/006 各多 1 块）。回填改为「首行用列表标记、后续行用等宽空格缩进」。

另外修正了三处**验证脚本口径**（不是迁移缺陷）：

- 旧站代码块有两种形态（`figure.highlight` 与裸 `<pre><code>`），最初基线只数前者，误报「代码块变多」。改为按 DOM 顺序合并统计。
- 旧站个别文章 HTML 标签畸形（未闭合 `<a>` 吞掉后文），「只比第一段」会误报。改为正文全文比对（排除代码块、去空白与零宽字符）。
- 只看全文文本对结构损失不敏感（表格压平后文字仍在）。核对抗项加入「正文表格数」与「逐块代码语言」；旧站无语言代码块（空 class）与新站 `plaintext` 视为等价。
